## 🌀 什么是 Hénon-Heiles 系统？

**Hénon-Heiles (1964)** 是天文学家 Michel Hénon 和数学家 Carl Heiles
提出的二维势能面混沌系统，最初用于研究星系动力学中的非轴对称势能。

### 势能函数

$$V(x,y) = x^2 y + \frac{y^3}{3}$$

这是一个**四极势能**（quadrupole potential），具有三次非线性项，
导致系统**不可积**——没有足够的守恒量来完整求解轨迹。

### Hamiltonian（哈密顿量）

$$H = \frac{p_x^2 + p_y^2}{2} + V(x,y) = \text{动能} + \text{势能} = \text{常数}$$

总能量 $E$ 是守恒的，这是系统的**唯一解析守恒量**。
除此之外系统**不可积**，因此必然存在混沌。

### 运动方程（Hamilton 方程）

$$\dot{x}  = \frac{\partial H}{\partial p_x} = p_x$$
$$\dot{y}  = \frac{\partial H}{\partial p_y} = p_y$$
$$\dot{p}_x = -\frac{\partial V}{\partial x} = -2xy$$
$$\dot{p}_y = -\frac{\partial V}{\partial y} = -(x^2 + y^2)$$

## 🦋 蝴蝶效应原理

混沌系统的核心特征：

1. **初值敏感依赖**：初始条件微小改变 → 轨迹指数级分离  
   分离速率由 **Lyapunov 指数** 描述，Hénon-Heiles 系统 $\lambda \approx 0.3$–$0.5$

2. **拓扑混合**：相空间中的混沌层（chaotic sea）不断拉伸折叠
   相同能量的轨道在不同区域表现截然不同：周期性 / 混沌性

3. **能量壁垒**：当 $E < 1/6$ 时，系统仍近似可积；  
   当 $E > 1/6$ 时，四极势能允许逃逸通道，混沌散射（chaotic scattering）出现

4. **Poincaré 截面**：混沌轨道在截面图上充满二维区域；  
   周期轨道仅留下离散的点。截面越密集 = 混沌越强

## 📐 Poincaré 截面解读

在 $y=0$ 平面（$\dot{y}=p_y>0$）记录每次穿越点：

| 图像特征 | 物理含义 |
|---------|---------|
| 闭合曲线岛链 | **不变环面**（准周期运动，可积近似）|
| 弥散点云 | **混沌层**（遍历性混沌）|
| 孤立点 | **周期轨道**（共振轨道）|
| 岛屿分裂 | **佩ircov 熔化**（从周期到混沌的转变）|

## 🔧 编译与运行

### 依赖

- **SFML 2.6+** (`libsfml-dev`)
- **g++** 支持 C++17

### 安装 SFML（Ubuntu/Debian）

```bash
sudo apt update
sudo apt install libsfml-dev
```

### 编译

```bash
cd daily-2026-05-30-henon-heiles
g++ -std=c++17 -O2 -o henon_heiles main.cpp \
    -lsfml-graphics -lsfml-window -lsfml-system
```

### 运行

```bash
# 图形模式（SFML 窗口）
./henon_heiles

# 终端模式（ASCII 图 + 能量数据）
./henon_heiles --terminal
./henon_heiles -t
```

### 退出

- 按 `Esc` 或关闭窗口

## 📊 算法细节

| 参数 | 值 | 说明 |
|------|----|------|
| 积分器 | **RK4** | 4阶 Runge-Kutta，精度 $O(h^4)$ |
| 时间步长 | `dt = 0.002` | 能量漂移 < 1e-5 |
| 轨道步数 | 30,000 | 足够长以展示长期混沌 |
| 绘制间隔 | 每 8 步 | 避免过度绘制 |
| Poincaré 门 | $\|y\| < 0.02$ 且 $p_y > 0$ | 上半平面穿越 |
